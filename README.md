# 小孩每日作息打卡

給家長用的手機網頁。放學後到睡覺前，家長在自己的手機上點選，畫面上用大字顯示下一件事，也可以把英文念出來給小孩看、給小孩聽。六項都完成，就得到一個笑臉 😊。笑臉會一天天累積。

畫面上的文字是英文，方便跟著發音。這份說明是中文。

沒有帳號，也不會把資料上傳。勾選和笑臉只存在這支手機的瀏覽器裡。

## 六項順序

1. Homework（寫功課）
2. Bath（洗澡）
3. Brush teeth（刷牙）
4. Pack school bag（整理書包）
5. Tidy up toys（收玩具）
6. Go to bed（上床睡覺）

想改顯示文字或圖示，打開 `index.html`，編輯腳本最上面的 `TASKS` 陣列。`label` 會顯示在畫面上，也會被念出來。`id` 請盡量不要改，否則當天已經勾過的項目會對不上。

## 每天怎麼用

1. 打開網頁（建議加到主畫面後，都從那個圖示開）。
2. 畫面中間最大的字就是下一件（Next）。按 **Hear it**，手機會用英文念出來。
3. 做完之後，家長按底下的 **Mark done**。下一件會換掉，並自動念出新的下一件。
4. 六項都完成，笑臉加 1，並說 “Great job! You earned a smiley!”
5. 點錯了可以按右上角的 **Undo**，或再點一次該項取消。若因此不滿六項，今天剛得到的那個笑臉會收回。
6. 勾選在台北時間每天 0:00 清空。笑臉不會清空。

請把音量打開。iPhone 側邊的靜音鍵要關掉，否則念不出聲音。若還是沒有聲音：到「設定 → 輔助使用 → 朗讀內容 → 聲音」，確認有英文（美國）的聲音。

## 用 GitHub Pages 發布

`index.html` 在倉庫根目錄，不需要建置。

1. 把 `main` 分支推上 GitHub。
2. 打開倉庫的 **Settings → Pages**。
3. **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選 **main**，資料夾選 **/ (root)**，按 Save。
5. 等一兩分鐘，網站會出現在 `https://<帳號>.github.io/Kids-routine/`。

倉庫裡有 `.nojekyll`，Pages 會直接提供這些檔案，不會用 Jekyll 過濾。

## 加到主畫面（可離線）

第一次請先連上網打開一次，讓檔案存進手機。之後沒有網路也能開。

請固定用同一種方式打開（都用主畫面圖示，或都用同一個瀏覽器）。有的手機會把「瀏覽器」和「主畫面」分成兩份資料，笑臉就不會在兩邊一起增加。

### iPhone（Safari）

1. 用 **Safari** 打開上面的網址。
2. 點下方的分享按鈕（方塊加上箭頭）。
3. 往下滑，選 **加入主畫面**，再按「加入」。
4. 之後從主畫面的圖示打開。

### Android（Chrome）

1. 用 **Chrome** 打開網址。
2. 右上角選單 → **加到主畫面** 或 **安裝應用程式**。
3. 確認後，主畫面會多一個圖示。

## 資料存在哪

只存在這台裝置、這個瀏覽器的 localStorage（鍵名 `kids-daily-routine-v1`）。清除這個網站的資料時，勾選和笑臉會一起消失。換手機不會跟著走。
